## Краткая справка
### Классы
```
struct MyClass{
private:
    int field1;
    bool field2;
    void some_private_method(){
    ...
    }
    
    ...
    
public:
    int field_N;
    void some_public_method(){
    ...
    }
    
};
```
Отличие ```struct``` от ```class``` - у ```struct``` все поля по умолчанию ```public```, а у класса ```private```

Если метод не меняет класс, нужно навесить на него спецификатор ```const``` чтобы его можно было использовать на константных объектах и ссылках

Конструкторы - особые методы без имени, чье возвращаемое значение совпадает с типом класса. Вызываются автоматически при создании объекта, можно делать перегрузки



## Домашнее задание
Задания необходимо делать последовательно. Каждое следующее задание расширяет предыдущее.
Необходимо сдать 2 файла - `day_time.cpp` и `day_time.h`.
### Задание 19
Напишите класс `day_time` - объект для работы с временем суток.

В этом задании необходимо реализовать следующие методы:

1 - `bool set_time(int h, int m, int s)` принимает время, проверяет корректность (часы 0-23, минуты и секунды 0-59). Если все ок — записывает и возвращает true. Если передали бред (например, 25:70:00) — не меняет объект и возвращает false.

2 - `int get_hours()` - возвращает часы. Метод должен работать на констатных объектах

3 - `int get_minutes()` - возвращает минуты. Метод должен работать на констатных объектах

4 - `int get_seconds()` - возвращает секунды. Метод должен работать на констатных объектах

5 - `std::string to_string` - возвращает строковое представление в формате `"hh:mm:ss"` (см. тесты). Не забудьте про ведущие нули. Метод должен работать на констатных объектах

### Задание 20

В этом задании необходимо дополнительно реализовать следующие методы:

1 - `void add_seconds(int seconds)` двигает время на `seconds` секунд вперёд

2 - `void add_minutes(int minutes)` двигает время на `minutes` минут вперёд

3 - `void add_hours(int hours)` двигает время на `hours` часов вперёд

Гарантируется, что аргументы неотрицательные.
